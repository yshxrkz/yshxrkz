## About me

I'm a BSc Cybersecurity student at Nottingham Trent University, graduating in 2028. I'm most interested in the defending side: reading what systems are telling you, spotting the attack in the noise, and building tools that make that faster.

Everything on this profile is something I built to learn by doing. Each repo explains how it works and what I took away from building it.

I'm looking for **cyber security placements and internships**.
