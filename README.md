## About me

I'm a **BSc Cybersecurity** student at **Nottingham Trent University**, graduating in **2028**. I'm interested in how attacks actually work and, more importantly, how to detect and stop them.

Most of what lives on this profile is practical security tooling I've built to learn by doing: analysing logs, scanning networks, spotting phishing and monitoring systems for changes. Every project has a README explaining how it works and what I learned building it.

I'm currently looking for **cyber security placements and internships**.

## Current focus

- Building hands-on security tools in Python and documenting them properly
- Learning detection and analysis from a blue-team / SOC perspective
- Strengthening my Linux and networking fundamentals
- Practising in CTF and lab environments and writing up what I learn
